Рантайм: 9.0.5
Система: Microsoft Windows 10.0.20348, X64

Класс Flag не наследует bool и не приводится к нему.
Перегружены только операторы true и false.

  if (yes)                сработал
  if (no)                 не сработал
  while с объектом        оборотов 3
  тернарный оператор      ветка да

Ради чего эта пара операторов и нужна

  yes && no               нет
  yes || no               да

Короткий && для своего типа собирается из трёх операторов:
& считает результат, а true и false решают, нужно ли вообще
вычислять правый операнд. Без пары true и false компилятор
короткий && не разрешит.

Приведения к bool у типа при этом нет:
  bool copy = yes;        не компилируется
  yes == true             не компилируется
